# Jira → Telegram Notifier (GitHub Actions)

Бот для автоматических уведомлений из Jira в Telegram (новые задачи, изменения полей, комментарии) на базе Python и GitHub Actions — без сервера и платного хостинга.

A serverless Python + GitHub Actions bot that sends Jira updates (new issues, field changes, comments) straight to Telegram.
